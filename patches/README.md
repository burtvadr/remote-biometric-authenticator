implement roadmap items. They are interdependent (patch 3 needs patch 1's
capabilities, patch 2's line CBOR), untested, and overlap with work already
done. Do not apply them wholesale. Implement each feature incrementally with
tests.

code against the current `main`. Do not `git am` these patches.
